# Sous-système de savoir
But : Permettre à l'IA de répondre à des questions sur des sujets présents dans la base de donnée wiki, et de créer du savoir pour les sujets non présents.

Création de savoir non présent dans la DB wiki. Dans le cas où le personnage demande une information sur un sujet non présent dans la base de donnée, le runtime peut faire appel à un sous-système de création de savoir pour que l'IA puisse inventer une réponse cohérente avec le contexte et les éléments déjà présents dans la base de donnée. Ce savoir permet d'alimenter une base de donnée locale à la partie.
